# ISO folder

Put your Windows 11 ISO here, named `Windows_11.iso`. To use another name or location, set the `iso_url` variable, e.g. `PKR_VAR_iso_url=./iso/Win11_English_x64.iso`.

Microsoft provides the ISO at [microsoft.com/software-download/windows11](https://www.microsoft.com/software-download/windows11).
